# Downloads and limitations

[Français](downloads.fr.md) | [Home](../README.md)

Reviewed downloads are listed on the [releases page](https://github.com/Anniiki/projet-oahu/releases).

The current development-tools snapshot contains five Windows x64 utilities:
installation, bank and database inspectors, plus native D3D12 texture and mesh
viewers. It includes guides, a binary manifest, licenses and SHA-256 checksums.
Use your own local game data; none is included.

These tools do not install a playable reconstructed game, restore online
services, or enable co-op. A final client-mod installer will be published only
after the relevant gameplay and connection paths have been validated.

The retained binary build records 107 passing CPU tests per Windows architecture.
GPU tests require suitable local hardware or WARP and were excluded from hosted
CI.
